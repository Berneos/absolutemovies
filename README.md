# 🎬 IAbsolute Cinema

**IAbsolute Cinema** é um aplicativo inteligente que utiliza **Inteligência Artificial** para recomendar filmes personalizados ao usuário, com base em seus gostos pessoais.

Criado como projeto da disciplina de **Android** no 3° ano do Ensino Médio Técnico em Informática, o app surgiu da necessidade de uma solução moderna e personalizada — já que **não existe nenhum app similar atualmente no mercado**.

Além de recomendar filmes, o usuário pode favoritar títulos, escolher gêneros preferidos e gerenciar suas preferências dentro de uma interface simples e intuitiva.

---

## 🚀 Tecnologias Utilizadas

### **Back-end**
- **Java 17**
- **Spring Boot**
- **PostgreSQL**
- **API REST** para comunicação com o aplicativo
- **Railway** (deployment)

### **Front-end / App**
- **HTML**
- **CSS**
- **JavaScript**
- **PWA (Progressive Web App)** — permitindo uso como aplicativo instalável no Android
